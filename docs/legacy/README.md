# Legacy Overhaust product history

This directory preserves the original Overhaust product narrative and design direction from the GitHub repository without treating it as the canonical implementation baseline.

Key themes retained from the original repo:

- Context reduction for AI usage and latency
- Memory as a persistent project layer for agent work
- Incremental project understanding instead of full re-ingestion
- Keeping the user-facing product simple and explainable
- Local-first operation for prototype and developer workflows

This material is archival and design-oriented. It should inform product decisions, not override the canonical Hermes engineering implementation.
