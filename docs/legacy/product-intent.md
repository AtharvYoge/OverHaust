# Original product intent

The original Overhaust concept positions the system as an AI memory layer that reduces redundant context and repeated reprocessing.

The historical intent is:

- avoid re-reading the same files, conversations, and decisions
- keep a persistent memory of project state and constraints
- provide the AI with only the relevant slice of project context
- let users understand what the system remembers and why
- preserve local-first trust and portability for prototype work

This intent remains valid and should be preserved in the canonical codebase even though the original implementation is older and less complete than the Hermes prototype.
